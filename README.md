# 일본어 동아리 스터디 조 편성 프로그램

희망 반(N1~N2 / N3~N5)과 가능 시간대를 바탕으로, 운영진 1명이 담당하는 스터디 조를 자동 편성하는 콘솔 프로그램.
부원 명단은 **엑셀에서 관리**하고, 프로그램은 명단 CSV를 읽어 **검증 → 편성 → 조 이동 → 결과 저장**을 담당한다.

## 실행 방법
```
javac -encoding UTF-8 *.java
java Main
```
- Windows 콘솔에서 한글이 깨지면 `chcp 65001` 후 실행
- IntelliJ/Eclipse: .java는 `src`에, CSV 파일은 프로젝트 루트(실행 위치)에 둔다
- 완료 기준 시험: `java ScenarioCheck` → `통과 22개 / 실패 0개` (sample_members.csv가 실행 위치에 있어야 함)
- GUI 시험: `java GuiCheck` → `통과 13개 / 실패 0개` (프로그램이 마우스·키보드를 직접 움직이므로 약 30초 동안 건드리지 않기)

## GUI 버전 실행
```
javac -encoding UTF-8 *.java
java GuiMain
```
- 처음에는 빈 화면으로 시작 → [CSV 불러오기]로 명단 파일을 직접 선택
- 콘솔 버전(`java Main`)과 같은 편성 로직을 사용하고 화면만 다름

| 화면 | 기능 |
|---|---|
| 위쪽 | 불러온 파일·인원 표시, [CSV 불러오기] [엑셀에서 열기] [조 편성 실행] [결과 저장] |
| 엑셀에서 열기 | 불러온 CSV를 엑셀(연결 프로그램)로 열기. 엑셀에서 저장하면 1.5초 안에 배너로 알리고 **[다시 불러오기]** 버튼 표시 (자동으로 다시 불러오지는 않음 — 편성 결과가 지워지므로) |
| 알림 배너 | 불러오기·편성·이동·저장을 할 때마다 무엇이 바뀌었는지 시간과 함께 표시 (잠깐 진한 색으로 깜빡임). 다시 불러오면 이전 명단과 비교해 **새로 추가 / 정보 수정 / 빠짐** 인원 표시 |
| 조 편성 탭 | 조 카드(조 색 띠·시간·운영진·인원·상태 꼬리표). **조 이름(연필 표시)을 누르면 이름 변경** (12자 이하, 쉼표·따옴표·'미배정' 불가, 중복 불가, 이동 기록에 남음, 다시 편성하면 원래 이름으로). 부원을 다른 조 카드로 **드래그**하거나 **오른쪽 클릭 → 다른 조로 이동**. 미배정 칸으로 끌면 조에서 빠짐 |
| 선택한 부원 카드 | 가능 시간, 현재 조, 옮길 수 있는 조. **초록 꼬리표를 누르면 그 조로 바로 이동** |
| 시간표 탭 | 주간 캘린더. 조 시간을 조 색 일정 블록으로 표시(겹치면 나란히). 부원을 선택하면 가능 시간은 연두색, 현재 조 파란 테두리(★), 옮겨갈 수 있는 조 초록 테두리(체크), 나머지는 흐리게. 일정을 누르면 조 카드로 이동 |
| 편성 보고서 탭 | 요약 숫자 → **확인 필요**(CSV 제외 줄·인원 미달·시간 안 맞는 부원) → 조별 편성표 → 미배정 표 → 수동 이동·이름 변경 기록 → 편성 기준·과정 |

## 부원 명단 (members.csv) 작성 규칙
| 학번 | 이름 | 레벨 | 반 | 운영진 | 가능시간 |
|---|---|---|---|---|---|
| 202533754 | 서유화 | 고급 | N1~N2 | Y | 월 19:00-21:00; 수 18:00-20:00 |

- 레벨: 노베이스 / 초급 / 중급 / 고급
- 반: N1~N2 / N3~N5
- 운영진: Y / N
- 가능시간: `요일 시작-끝`, 30분 단위, 09:00~23:00, 여러 개는 `;` 또는 `,`로 구분
- 엑셀에서 저장할 때는 **CSV UTF-8(쉼표로 분리)** 권장 (일반 CSV로 저장해도 읽을 수 있음)
- 처음 시작할 때는 `sample_members.csv`를 복사해 `members.csv`로 이름을 바꿔 사용

## 메뉴
| 번호 | 기능 |
|---|---|
| 1 | CSV 불러오기 / 다시 불러오기 (엑셀 수정 후 재실행 없이 반영). 잘못된 줄은 줄 번호와 사유를 표시하고 제외 |
| 2 | 부원 목록 (반별, 운영진 먼저) |
| 3 | 조 편성 실행 — 편성 기준, 반별 편성 과정, 조별 시간 선정 이유를 함께 출력 |
| 4 | 편성 결과 보기 |
| 5 | 다른 조 추천 / 조 이동 — 학번 입력 시 같은 반의 다른 조를 '참여 가능' 먼저 바로 표시, 번호로 이동. `T`로 바뀐 시간표를 임시 입력해 다시 확인. 시간이 안 맞는 조도 확인 후 이동 가능(기록에 표시) |
| 6 | 편성 결과 저장 → `result.csv` (엑셀용, 한 줄 = 한 사람, 참여가능시간·비고 포함) |

## 편성 기준 (프로그램 출력 문구와 동일)
1. N1~N2 희망자는 심화조, N3~N5 희망자는 기본조로 나눠서 편성합니다.
2. 운영진 1명이 조 1개를 맡고, 운영진도 그 조에서 같이 공부합니다.
3. 스터디 시간은 1시간이며, 조장인 운영진의 스터디 가능 시간 중에서 정합니다.
4. 조 시간은 반마다 가능한 조합을 비교해, 미배정 부원이 가장 적은 조합으로 정합니다. (같으면 인원 미달 조가 적고 조 인원이 고른 조합)
5. 부원은 참여 가능한 시간의 조에만 편성됩니다.
6. 배정 가능한 조의 수가 적은 부원부터 먼저 조에 배치합니다.
7. 배정 가능한 조가 여러 개면 사람이 가장 적은 조에 배치됩니다.
8. 배정이 완료된 뒤 조끼리 인원 차이가 큰 경우 다른 시간도 가능한 부원을 옮겨 인원을 맞춥니다.
9. 운영진 포함 5명이 안 되는 조는 따로 알려 줍니다. (심화조는 고급자가 적어 5명 미만도 허용)

## 설계 변경 기록
- 부원 등록·수정·삭제를 콘솔 메뉴에서 제거하고 엑셀(CSV) 편집으로 대체
  - 이유: 40~50명을 콘솔로 한 명씩 입력·수정하는 것보다 엑셀 표 편집이 실사용에 훨씬 편함. 추후 구글 폼 응답 시트 → CSV로 연결 가능
  - 보완: 불러올 때 항목별 검증 + 오류 줄 안내, 재불러오기 메뉴, 인코딩 자동 판별
- 시간표 변경 기능은 파일을 수정하지 않고 "임시 시간표로 추천 → 조 이동"만 수행 (명단 원본은 엑셀 하나로 유지)
- 편성 결과는 엑셀용 `result.csv`로만 저장 (txt 보고서 저장은 제거, 보고서는 콘솔 3·4번에서 확인)
- 조 이름을 A/B에서 심화(N1~N2)/기본(N3~N5)으로 변경
- 편성 기준·과정·시간 선정 이유 문구를 처음 보는 사람도 이해할 수 있는 쉬운 말로 변경
- (시험 후 수정) 1시간 연속 가능 시간이 없는 운영진이 결과·CSV에서 사라지던 문제 → 미배정 목록에 사유와 함께 남김 (AC-12)
- (시험 후 수정) 조 이동 뒤에도 "최소 인원 미달" 경고가 그대로 남던 문제 → 인원 경고를 출력할 때마다 현재 조 상태로 계산 (AC-14)

- GUI 추가: 콘솔에서 학번·번호로 하던 조 이동을 드래그/오른쪽 클릭으로, 결과 확인을 조 카드·시간표로 바꿈
  - 편성 로직(GroupMatcher, MatchResult)은 그대로 두고 화면 클래스만 추가 → 콘솔·GUI가 같은 결과를 냄
  - `MatchResult.unassign()` 추가: 부원을 조에서 빼 미배정으로 돌리기 (이동 기록에 남음)

- GUI 디자인 개선 (TimeTree 앱 참고): 윈도우 기본 모양 대신 흰 바탕·초록 포인트 색·둥근 카드·파스텔 조 색·이름 아바타로 변경, 시간표를 주간 캘린더로 변경
  - 불러오기 후 화면 변화가 잘 안 보이던 문제 → 알림 배너 + 이전 명단과 비교 표시
  - 텍스트만 있던 편성 보고서 → 요약 숫자와 표로 정리
  - 글꼴에 없을 수 있는 기호(체크, 경고)는 글자 대신 직접 그림 (Windows 맑은 고딕에서 네모로 깨지지 않게)

- 엑셀에서 열기 + 파일 변경 감지 추가 (부원 추가·수정·삭제는 프로그램에 넣지 않고 엑셀 관리 유지 — 원본을 하나로 두기 위해)
- 조 이름 변경 추가: `Group.setName`, `MatchResult.rename` (변경 내용은 수동 이동 기록과 함께 남김)

- 화면 정리 (눈에 띄는 색·아이콘이 너무 많아 가독성이 떨어지던 문제)
  - 색은 의미가 있을 때만: **빨강 = 문제, 초록 = 할 수 있는 행동, 파랑 = 지금 선택한 것**, 나머지는 회색
  - 조 색 10가지 → 반별 차분한 2가지, 부원 색깔 아바타·운영진/인원 꼬리표 제거(회색 글씨로), 정상 조의 상태 표시 제거
  - 연필(이름 변경)은 마우스를 올렸을 때만, 시간표의 ★·체크·경고 아이콘 제거(테두리로만 구분)

- 사용성 수정 (11/18)
  - 시간표: 스크롤 없이 남은 높이에 맞춰 30분 칸 높이를 자동 조절 → 9시~23시가 한 화면에
  - 미배정 카드를 조 편성 화면 아래에 고정. 드래그 중 화면 위·아래 끝에 가져가면 자동 스크롤 → 맨 위 심화조 카드까지 옮길 수 있음
  - 조 카드 위에서도 마우스 휠로 조 편성 화면 스크롤 (조 카드 안쪽 스크롤 영역 제거)
  - 부원 명단에서 부원을 눌러도 명단 탭에 머무름 (확인 필요 탭에서 누를 때만 조 카드로 이동)
  - 이름 줄과 가능 시간 줄의 시작 위치 맞춤 (`Theme.row`가 맨 앞에 간격을 넣지 않도록)

- 화면 단순화 (11/19): 부원 명단 탭을 없애고 조 편성 화면 하나만 사용. 프로그램 시작 시 CSV 자동 불러오기 제거

- 확인 필요 탭 삭제 (11/19): 같은 내용을 편성 보고서 맨 위 "확인 필요"에서 확인. 화면 안내 문구를 짧게 정리

- 12주차 피어 리뷰·자기 점검 반영 (11/19)
  - 조 이름 검사를 화면(ClubPanel)에서 `MatchResult.checkGroupName`으로 옮김 → 시험 코드로 확인 가능 (AC-18, AC-19)
  - 조 이름을 '미배정'으로 바꿀 수 있던 문제 수정 (result.csv에서 미배정 부원과 구분 불가)
  - 미배정으로 옮기기(AC-20), 다시 불러오기 비교(AC-21) 시험 추가
  - GUI 조작 시험 GuiCheck(G-01~G-13) 추가 — 수정 전 코드에서는 G-09('미배정' 이름 거절) 실패
  - 운영진 없는 임시 조 만들기는 넣지 않음 (조 시간을 운영진 가능 시간에서 정하는 구조, 운영진 증원 시 재편성으로 대응)

- 조 시간 조합 비교 추가 (11/22)
  - 이유: 운영진 조 시간을 한 명씩 차례로 정하면 앞 조의 선택이 뒤 조를 막아, 다른 조합이면 들어갈 수 있는 부원이 미배정됨 (샘플에서 금 17시만 가능한 기본반 부원 2명)
  - 1차로 고른 시간에서 시작해 조합을 시험 배정해 보고 미배정 → 인원 미달 조 → 인원 차이 순으로 더 나은 조합으로 교체. 조합이 10만 가지 이하면 모두 비교, 넘으면 한 조씩 바꿔 보며 개선
  - 샘플 결과: 미배정 6명 → 4명, 인원 미달 조 2개 → 1개 (계산 1초 미만). 시험 AC-22 추가, 시연 순서·GuiCheck 대상 부원 변경
